# Модуль Contract - Документация

## Описание
Новый модуль **Contract** (Договоры) предназначен для управления договорами с правообладателями. Создан по образцу модуля `rightHolders` с полной интеграцией и без дублирования кода.

## Структура Модуля

```
features/contracts/
├── ContractPage.jsx              # Главная страница
├── contracts.css                 # Стили
├── api/
│   └── contracts.api.js          # API функции
├── components/
│   ├── ContractGrid.jsx          # Компонент таблицы
│   ├── contractColumns.jsx       # Описание колонок
│   └── contractFilterFields.js   # Поля фильтра
├── editor/
│   ├── ContractForm.jsx          # Форма договора с RightHolder selector
│   └── RightHolderSelector.jsx   # Компонент выбора/создания правообладателя
└── hooks/
    └── useContracts.js           # Хук для управления состоянием
```

## Основные Компоненты

### 1. ContractPage.jsx
Главная страница управления договорами. Содержит:
- Фильтрацию по статусу, типу направления и правообладателю
- Inline редактор (create/view/edit режимы)
- Кнопку добавления нового договора
- Сохранение фильтров в localStorage

### 2. ContractForm.jsx
Форма редактирования договора с поддержкой:
- Выбора правообладателя из справочника (RightHolderSelector)
- Ввода номера договора
- Выбора статуса (DRAFT, ACTIVE, TERMINATED)
- Выбора типа направления (DIRECT_ARTIST, LABEL_CATALOG)
- Ввода дат (подписи, начала и конца действия)

**Важно:** Форма использует RightHolderSelector для выбора правообладателя

### 3. RightHolderSelector.jsx
Компонент для выбора правообладателя:
- Dropdown со списком всех правообладателей
- Кнопка "➕ Новый" для создания нового правообладателя
- **Встроенная форма создания** использует RightHolderForm из модуля rightHolders
- При создании нового правообладателя автоматически обновляется список

**Ключевая особенность:** Полностью использует RightHolderForm из модуля `features/rightHolders/editor/RightHolderForm.jsx` без дублирования кода.

### 4. ContractGrid.jsx
Таблица со списком договоров:
- Отображение ID, номера договора, правообладателя, статуса, типа направления
- Даты подписи, начала и конца действия
- Кнопки редактирования и удаления
- Валидация перед удалением

## Поля Договора

| Поле | Тип | Обязательное | Описание |
|------|-----|-------------|---------|
| id | int | да | ID договора |
| rights_holder_id | int | да | ID правообладателя |
| contract_number | string | да | Уникальный номер договора (макс 255 символов) |
| status | string | да | DRAFT, ACTIVE, TERMINATED (по умолчанию DRAFT) |
| direction_type | string | нет | DIRECT_ARTIST, LABEL_CATALOG |
| signed_date | date | нет | Дата подписи договора |
| valid_from | date | нет | Дата начала действия |
| valid_to | date | нет | Дата конца действия |

## Фильтры

На странице доступны следующие фильтры:
- **Поиск** - поиск по номеру договора
- **Статус** - фильтр по статусу договора
- **Тип направления** - фильтр по типу направления
- **Правообладатель** - фильтр по правообладателю

Фильтры сохраняются в localStorage автоматически.

## Навигация

Модуль доступен через главное меню:
- Пункт меню: **📝 Договоры**
- Доступен после аутентификации
- Использует тот же шаблон навигации как другие модули

## API Endpoints

Модуль использует следующие API endpoints:
```
GET    /v1/contracts           # Список договоров с фильтрацией
GET    /v1/contracts/{id}      # Детали договора
POST   /v1/contracts           # Создание договора
PUT    /v1/contracts/{id}      # Обновление договора
DELETE /v1/contracts/{id}      # Удаление договора
```

## Интеграция с RightHolders

**Отсутствие дублирования кода:**

Вместо создания отдельной формы для правообладателя в модуле Contract, используется компонент `RightHolderForm` из модуля `rightHolders`:

```jsx
// RightHolderSelector.jsx импортирует и переиспользует:
import { RightHolderForm } from '../../rightHolders/editor/RightHolderForm';

// Встроенная форма создания нового правообладателя:
<RightHolderForm
  rightHolderId={null}
  mode="create"
  onDone={handleCreateDone}
  onCancel={handleCancel}
/>
```

**Преимущества:**
- Одна реализация формы правообладателя для обоих модулей
- Соответствие требованиям и структуре
- Упрощение поддержки и обновления
- Консистентность пользовательского интерфейса

## Использование

### Добавление нового договора
1. Нажмите кнопку "➕ Новый договор"
2. В форме выберите правообладателя из dropdown или создайте нового (кнопка "➕ Новый")
3. Заполните номер договора и другие поля
4. Нажмите "Сохранить"

### Создание нового правообладателя из страницы договора
1. В форме договора нажмите кнопку "➕ Новый" рядом с выбором правообладателя
2. Откроется встроенная форма с полным функционалом создания правообладателя
3. Заполните данные (см. модуль RightHolders для полной информации)
4. Нажмите "Сохранить" в форме правообладателя
5. Правообладатель создастся и автоматически выберется в договоре

### Редактирование договора
1. В таблице нажмите кнопку "✎ Редактировать"
2. Отредактируйте необходимые поля
3. Нажмите "Сохранить"

### Просмотр деталей
1. В таблице нажмите на номер договора
2. Откроется форма в режиме просмотра
3. Для редактирования нажмите "✎ Редактировать"

## Часто Используемые Действия

```javascript
// Получение списка договоров с фильтрацией
const { items, total } = await getContracts({ 
  limit: 50, 
  offset: 0,
  status: 'ACTIVE',
  rights_holder_id: 123
});

// Создание договора
const newContract = await createContract({
  rights_holder_id: 123,
  contract_number: 'CT-2024-001',
  status: 'DRAFT',
  direction_type: 'DIRECT_ARTIST'
});

// Обновление договора
await updateContract(contractId, {
  status: 'ACTIVE',
  valid_from: '2024-01-01'
});

// Удаление договора
await deleteContract(contractId);
```

## Примечания

- Договор всегда должен иметь связанного правообладателя (поле обязательное)
- Валидация дат проверяется на сервере: `valid_from` не может быть позже `valid_to`
- При удалении договора связанные права должны быть удалены или переназначены заранее
- Все операции сохраняют фильтры в localStorage автоматически
